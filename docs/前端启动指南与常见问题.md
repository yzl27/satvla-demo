## 启动顺序：必须先后端、再前端

### 第一步：启动后端 `api_bridge.py`

```bash
cd /home/c303-1/ljy/multiagent
conda activate wcj-multiagent
python api_bridge.py
```

看到类似 `Uvicorn running on http://0.0.0.0:8000` 即表示后端就绪。

> **注意**：后端用的是 `wcj-multiagent` 这个 conda 环境，不是其他环境。

---

### 第二步：启动前端开发服务器（新开一个终端）

```bash
cd /home/c303-1/ljy/SatLab/SatVLALab/SatVLALab/frontend-demo

# 首次运行需安装依赖
npm install

# 启动
npm run dev
```

前端默认跑在 **端口 5174**（`vite.config.ts` 里配置的）。

---

### 第三步：访问页面

在浏览器打开：**`http://localhost:5174`**

---

## 另一台机器通过 SSH 访问的方法

前端代码里后端地址写死为 `localhost:8000`，所以如果另一台电脑想用，**最简单的方式是用 SSH 端口转发**，不需要改代码：

```bash
# 在另一台电脑的终端执行
ssh -L 5174:localhost:5174 -L 8000:localhost:8000 c303-1@10.254.12.51
```

然后在那台电脑的浏览器直接打开 `http://localhost:5174` 就行了，后端 `localhost:8000` 也会自动通过隧道映射过来。

## 常见问题

| 现象 | 原因 | 处理 |
|------|------|------|
| 点执行没反应、图不加载 | 后端 `api_bridge.py` 没启动 | 先启动第一步 |
| 默认图片不显示 | `multiagent/data/100000007.png` 不存在 | 确认文件在 `/home/c303-1/ljy/multiagent/data/` 下 |
| 端口冲突 | 8000 或 5174 被占用 | `lsof -i:8000` 查看并 kill |
